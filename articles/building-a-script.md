# Building a script

- Install Youtube Summary with chatGPT browser add-on

- Copy the full transcript

- paste into Claude with the prompt: Analyze this expose, I want you to rewrite completely to be original as as following these directions in your rewrite.

The key elements I'll maintain:

**Strong opening hook** that immediately establishes the crisis

- **Clear data presentation** with numbers given breathing room ("The number: X. The figure: Y")

- **Controlled use of metaphors** - impactful but not overwhelming

- **Smooth paragraph transitions** that explicitly connect ideas

- **Mixed sentence structure** for pacing control

- **Knowing but not cynical tone** - concerned without preaching

- **~2000 words** flowing naturally without subheadings

- **Statistics woven clearly** into the narrative without drowning it

- **Building momentum** toward a synthesis conclusion

- **Strong closing call to action** that challenges readers to engage

- Result should not have sub-headings: get rid of the subheadings, just flow from paragraph to paragraph 

- iterate: analyze this latest version against the original I posted. What are the strenth and weaknesses of each. How would you improve yours if at all.
