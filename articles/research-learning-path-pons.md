# Research - Learning Path Pons

# Product Owner AI Language Solutions: 21-Tage-Interviewvorbereitung
Das bevorstehende zweite Interview bei PONS Langenscheidt GmbH mit CEO Dr. Lars Janzik und dem Head of Product erfordert eine strategische Vorbereitung auf mehreren Ebenen. Diese Analyse zeigt: **Dr. Janzik ist selbst zertifizierter Scrum Product Owner** (seit 2015), was bedeutet, dass er fundierte PO-Methodik-Fragen stellen wird. Das praktische Testszenario wird wahrscheinlich eine Feature-Priorisierung oder Produktstrategie-Aufgabe für den **Langenscheidt Language Coach** umfassen – das AI-basierte Sprachlernprodukt, das im Oktober 2024 gelauncht wurde.

Die Unternehmensstruktur ist komplex: PONS Langenscheidt GmbH gehört zur Klett-Gruppe, und **Laniqo** – ein Joint Venture mit der Adam-Mickiewicz-Universität in Poznań – entwickelt die AI-Technologien für domänenspezifische Übersetzung. Dieser B2B-Fokus auf Sprachschulen und Unternehmen unterscheidet PONS von Consumer-Playern wie Duolingo.

### Tag 9: LLM-Architekturen und RAG für Sprachlernen
**Aktionspunkte:**

- LLM-Optionen für Language Learning verstehen (GPT-4, Claude, Open Source)

- RAG-Konzept für Bildungskontexte erfassen

- Praktische Implikationen für Produktentwicklung dokumentieren

**LLM-Auswahl für Sprachlernen:**

- **GPT-4/GPT-4o:** Industry-leading für Tutoring-Konversationen, Grammatik-Erklärungen

- **Claude (Anthropic):** Nuancierte, sicherheitsfokussierte Antworten

- **Open Source (LLaMA 3, Mistral 7B):** Kostengünstig für High-Volume

**RAG (Retrieval-Augmented Generation) für Bildung:**

- Indexierung: Vokabellisten, Grammatikregeln in Embeddings konvertieren

- Speicherung: Vector-Datenbank (Pinecone, Weaviate, Chroma)

- Retrieval: Semantisch ähnliche Dokumente zur Query finden

- Augmentation: Gefundene Inhalte zum LLM-Prompt hinzufügen

- Generation: LLM generiert Antwort basierend auf retrieval

**Vorteile:** Reduziert Halluzinationen, ermöglicht dynamische Updates, günstiger als kontinuierliches Fine-Tuning.

### Tag 12: User Stories und Akzeptanzkriterien
**Aktionspunkte:**

- INVEST-Kriterien memorieren

- 5 User Stories für Language Coach schreiben

- Given-When-Then-Format üben

**INVEST-Kriterien:**

- **I**ndependent: Unabhängig entwickelbar

- **N**egotiable: Details verhandelbar

- **V**aluable: Liefert Nutzerwert

- **E**stimable: Team kann Aufwand schätzen

- **S**mall: In einem Sprint umsetzbar

- **T**estable: Klar prüfbar

**Beispiel User Story für Language Coach:**

Als Deutschlerner auf A2-Niveau
möchte ich AI-generierte Übungen zu meinem Berufsfeld (Krankenpflege) erhalten
damit ich berufsspezifisches Vokabular gezielt trainieren kann

Akzeptanzkriterien:
Given ich habe "Krankenpflege" als Berufsfeld ausgewählt
When ich eine neue Übung starte
Then enthält die Übung mindestens 5 berufsspezifische Vokabeln
And die Übung ist auf mein CEFR-Level angepasst
And ich erhalte sofortiges Feedback zu meinen Antworten
